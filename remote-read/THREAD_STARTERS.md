# ROPEJUMP reviewer thread starter

Fixed A/B/C/D starters are retired.

All reviewer threads use the same common worker contract:
`ops/jumprope-research/REVIEW_WORKER.md`

After a thread has this project context, normal user messages may be only:
- `10개 진행`
- `N개 진행`
- `확인해`
- `진행`

The thread must claim unlocked work atomically through the dynamic queue before reviewing anything.
